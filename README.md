# CustomRP Presets

A cleaned and organized collection of CustomRP presets maintained by **Dragon / @dragongraf**.

These presets are organized into Personal, Requested, General, and Community sections. Modernized presets have their old Discord Application ID removed, so presets that use direct image URLs do not depend on one of Dragon's temporary applications.

- CustomRP project: https://github.com/maximmax42/Discord-CustomRP
- Preset requests: https://discord.com/channels/928333025652121630/1048650650499686450
- Questions: Discord `@dragongraf`

## Notes

- Every `.crp` in this repository has an empty Application ID after the overhaul.
- Local previews live in `assets/previews/` and show the **current modernized preset values**.
- When an original Discord preview was known, its original URL is retained in `presets.json`. Old signed Discord CDN links may expire.
- Historical presets whose original `.crp` attachment was no longer available were conservatively reconstructed and are identified in `AUDIT.md` / `presets.json`.
- The only community presets included are the two that were already in the repository.
